=== -- [QB01B] 보너스 1: 서브쿼리 방식 - 주문 내역이 존재하는 매장 목록 조회 (Subquery IN) ===
[SQL]:
SELECT id, name AS store_name, phone
FROM store
WHERE id IN (SELECT DISTINCT store_id FROM orders)
ORDER BY id ASC;
